
git では [.gitignore] というファイルに除外ルールを記載する事で、
ファイル更新差分として表示されず、
git へアップロードしないファイルやフォルダを指定する事が出来ます。

用途としては、
オブジェクトフォルダやライブラリフォルダ等、
プロジェクトを開く時に自動生成される物などを指定します。

※CakePHPでの除外ルール
CakePHPでプロジェクトを作成すると、
自動的に [.gitignore] が生成され、
その中の除外ルールで

/config/app.php
/logs/*
/tmp/*
/vendor/*

という項目があります。
このファイルは自動生成されないので、
git経由で、他の環境にプロジェクトを持っていく際には
このルールを削除しコミットするか、
USB等別の方法で持ち運ぶようする必要があります。
